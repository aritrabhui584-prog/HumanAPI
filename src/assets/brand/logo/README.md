# HumanAPI Brand Logo

- Reusable component: `src/components/brand/HumanAPILogo.tsx`
- Preserves transparent background and original aspect ratio
- Responsive desktop sizing (approx. 110–150px) and mobile sizing (approx. 90–115px)
- Supports dark/light variations and fallback placeholder bounding geometry
